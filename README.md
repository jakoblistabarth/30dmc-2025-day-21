# Contribution to the 30DayMapChallenge 2025

Day 21: Icons

This repository is a Vite project that uses D3 as the primary visualization dependency to create an animated map.

## Overview

This repository is a Vite-based frontend app intended. It also contains a production build setup (github actions).

## Getting started

1. Install dependencies:

```bash
npm install
# or
pnpm
```

2. Run the dev server (hot-reload):

```bash
npm run dev
# or
pnpm dev
```

Open the URL printed by Vite (usually http://localhost:5173).

3. Create a production build:

```bash
npm run build
# or
pnpm build
```

4. Preview the production build locally:

```bash
npm run preview
# or
pnpm preview
```

## Typical package.json scripts

```json
{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  }
}
```
